# Letter Blog

## 概要

**勉強したら勉強しっぱなし**  
**制作物作ったら作りっぱなし**  
**記事を書いたら書きっぱなし**

そんなことありませんか？

せっかくアウトプットしたのに、アウトプットやりっぱなしで  
内容をそんなに覚えていないと勿体無いですよね？

やりっぱなしを解消するための復習ができるBlogということで
**Letter Blog**
という制作物を作成しています。

## 機能(予定)

- 簡単に投稿しやすい**Blogテンプレート**
- エビングハウスの忘却曲線に基づいた**復習リマインド**
- 頑張った自分から復習のお手紙が届く**復習問題お手紙機能**

## 技術スタック(予定)

- Next.js (フロント)
- supabase (BaaS)
- AWS (デプロイ)
- cookie (認証)
- Github Actions(CI/CD)
